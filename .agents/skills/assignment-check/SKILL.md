# 제출 전 과제 점검

학생이 지정한 과제 파일(없으면 어느 파일인지 먼저 묻는다)을 아래 순서로 점검한다.
**파일을 고치지 않는다.** 결과는 표로 보고하고, 고치는 일은 학생이 한다.

1. **요구사항**: 같은 폴더에 과제 설명 파일이 있으면 읽고, 요구 항목마다 충족 / 부족 / 확인 불가를 표시한다.
2. **분량·형식**: 글자 수(또는 단어 수), 제목·소제목 구성, 파일 형식을 적는다.
3. **출처**: 인용문·통계·논문 이름마다 출처가 붙어 있는지 확인한다. 출처 없는 주장 문장을 줄 번호와 함께 나열한다.
   출처가 실제로 있는지는 AI가 보장할 수 없으므로 "원문 확인 필요"라고 적는다.
4. **코드 과제**: 실행 방법이 적혀 있는지, 실행했을 때 오류가 나는지 확인한다. 실행 전에 학생에게 허락을 받는다.
5. **개인정보**: 학번·전화번호·주민번호가 파일에 들어 있으면 알린다.
6. **AI 사용 기록**: `AI-사용기록.md`에 이번 과제 기록이 있는지 확인한다.
