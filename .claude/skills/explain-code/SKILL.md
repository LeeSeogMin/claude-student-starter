# 단계별 설명

1. 설명할 대상(파일·줄 범위·개념)을 확인한다. 불분명하면 먼저 묻는다.
2. **한 문장 요약**: 이 코드(개념)가 무엇을 하는지 한 문장으로 말한다.
3. **줄 단위 설명**: 핵심 줄을 5개 이내로 골라, 각 줄이 무엇을 하는지 쉬운 말로 설명한다.
   전문용어는 처음 나올 때 한 문장으로 풀어 쓴다.
4. **실제 값으로 따라가기**: 작은 입력 예를 하나 정하고, 그 값이 코드에서 어떻게 바뀌는지 순서대로 보여 준다.
5. **확인 질문**: 학생이 이해했는지 확인하는 질문을 2개 낸다. 답은 학생이 답한 뒤에 알려 준다.

코드를 고치지 않는다. 학생이 고쳐 달라고 하면 이 스킬을 끝내고 일반 대화로 돌아간다.
