# 03. VS Code에서 AI 도구 쓰기

세 도구의 화면은 조금씩 다르지만 쓰는 방법은 같다: **폴더 열기 → 채팅 창 열기 → 파일을 지정해 요청 → 허락 창 확인**.

## 공통 순서
1. VS Code에서 **파일 → 폴더 열기**로 내 과제 레포 폴더를 연다. AI는 **열린 폴더 안**만 본다.
2. 채팅 창을 연다.
   - Claude Code: 오른쪽 아래 **✻ Claude Code** 또는 오른쪽 위 불꽃 아이콘
   - Copilot: 상단 채팅 아이콘 또는 `Ctrl+Alt+I`(Mac `Ctrl+Cmd+I`)
   - Codex: 왼쪽 막대의 Codex 아이콘
3. 요청을 쓴다. `@`를 치고 파일 이름을 고르면 그 파일을 콕 집어 보여 줄 수 있다. 예: `@assignments/01-보고서/초안.md 서론을 점검해 줘`
4. AI가 파일을 고치거나 명령을 실행하려 하면 **허락 창**이 뜬다. 무엇을 하려는지 읽고 누른다.

## Claude Code 화면에서 알아 둘 것
| 기능 | 하는 방법 | 언제 쓰나 |
|------|----------|----------|
| 파일 지정 | `@파일이름`, 줄 범위는 `Alt+K`(Mac `Option+K`) | 특정 파일·줄만 보게 할 때 |
| plan 모드 (계획만 세우고 파일은 안 고침) | 입력창 아래 모드 표시를 눌러 **Plan** 선택, 또는 `/plan` | 큰 과제를 시작할 때 먼저 순서를 보고 싶을 때 |
| 되돌리기 | 메시지 위에 마우스를 올리면 나오는 되감기 버튼 → **Rewind code to here** | Claude가 고친 내용이 마음에 안 들 때 |
| 스킬 실행 | `/assignment-check`, `/explain-code` | 이 템플릿에 넣어 둔 정해진 작업(05번 문서) |
| 규칙 보기 | `/memory` | Claude가 읽는 규칙 파일을 열어 볼 때 |

## Copilot·Codex에서 다른 점
- **Copilot**: 채팅 창 위쪽에서 모드를 고른다. 파일을 직접 고치게 하려면 **Agent** 모드를 쓴다. 질문만 할 때는 **Ask** 모드.
- **Codex**: 승인 방식이 `.codex/config.toml`에 정해져 있다(이 템플릿: 폴더 안만 쓰기, 필요하면 묻기).
- 세 도구 모두 이 폴더의 `AGENTS.md` 규칙을 읽는다. 그래서 같은 요청에 비슷한 태도(한국어, 이유 설명, 통째로 대신 쓰지 않기)로 답한다.

## 허락 창에서 "예"를 누르기 전에
- **어느 파일**을 바꾸는지 본다. 과제 폴더 밖이면 "아니요".
- **명령어**라면 무슨 뜻인지 모를 때 "아니요"를 누르고 "이 명령이 무슨 뜻이야?"라고 묻는다.
- "다시 묻지 않기(always allow)"는 `git status`처럼 읽기만 하는 명령에만 쓴다.
