# 02. Claude 채팅창과 VS Code 속 Claude는 무엇이 다른가

Claude는 같은 AI 모델이지만, **어디에서 쓰느냐**에 따라 할 수 있는 일이 다르다.

- **채팅창(claude.ai)**: 웹브라우저나 Claude 앱에서 대화하는 방식이다. 사람이 파일을 직접 올리고, 답을 복사해 가야 한다.
- **VS Code 속 Claude(Claude Code 익스텐션)**: VS Code라는 편집 프로그램 안에서 쓰는 방식이다.
  Claude가 **내 컴퓨터의 과제 폴더를 직접 읽고, 파일을 고치고, 명령을 실행**한다. 고치기 전에는 나에게 허락을 받는다.

VS Code 안에서 쓰는 AI 도구는 Claude Code 말고도 **GitHub Copilot**, **OpenAI Codex**가 있다. 셋 모두 아래 표의 오른쪽 칸처럼
폴더를 직접 다루며, 이 템플릿은 세 도구가 같은 규칙 파일(`AGENTS.md`)을 읽도록 맞춰 두었다. ChatGPT 채팅창과 Codex의 관계도
claude.ai 채팅창과 Claude Code의 관계와 같다.

## 비교표

| 항목 | 채팅창 (claude.ai) | VS Code 속 Claude (Claude Code) |
|------|-------------------|-------------------------------|
| 파일 읽기 | 내가 파일을 하나씩 업로드해야 Claude가 읽는다 | Claude가 열린 폴더 안의 파일을 스스로 찾아 읽는다 |
| 파일 고치기 | Claude가 답을 보여 주면 내가 복사해 붙여 넣는다 | Claude가 파일을 직접 고치고, 바뀐 줄을 빨강·초록으로 보여 준다 |
| 프로그램 실행 | 할 수 없다 (일부 분석 기능 제외) | 파이썬 실행, 시험 돌리기, git 명령을 Claude가 실행한다 (허락 후) |
| 규칙 기억 | 대화마다 다시 설명해야 한다 (프로젝트 기능 제외) | 폴더의 `CLAUDE.md` 규칙을 매번 자동으로 읽는다 |
| 기록 남기기 | 대화 기록만 남는다 | Git으로 파일의 변경 이력이 남고 GitHub에 올릴 수 있다 |
| 배우기 쉬움 | 바로 쓸 수 있다 | 설치가 필요하다 (이 레포의 01번 문서) |
| 잘 맞는 일 | 개념 질문, 아이디어 정리, 짧은 글 다듬기 | 여러 파일로 된 과제, 코드 작성·디버깅, 보고서 초안을 파일로 관리 |

## 언제 무엇을 쓸까

- **개념이 궁금하다** ("회귀분석이 뭐야?") → 채팅창이 빠르다.
- **과제 폴더 안의 파일을 함께 다뤄야 한다** ("data.csv를 읽어서 그래프를 그리는 코드를 만들고 실행해 줘") → VS Code.
- **같은 과제를 며칠에 걸쳐 고친다** → VS Code + GitHub. 어제 무엇을 바꿨는지 Git 기록으로 확인한다.

## 주의
- 두 방식 모두 같은 Claude 계정으로 로그인한다. 다만 **VS Code에서 쓰는 Claude Code는 유료 요금제가 필요**하다(01번 문서 참고).
- Claude가 파일을 직접 고치므로, 고치기 전에 Claude가 묻는 허락 창을 **읽고** 누른다. 무엇을 바꾸는지 모르면 "아니요"를 누르고 물어본다.
