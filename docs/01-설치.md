# 01. 설치하기 (Windows · Mac)

설치 순서: **Git → GitHub 계정 → VS Code → AI 도구(Claude Code / Copilot / Codex 중 하나 이상)**.
AI 도구는 세 개 다 설치할 필요가 없다. 가진 요금제에 맞는 것 하나부터 시작한다.

| AI 도구 | 만든 회사 | 필요한 계정·요금제 (2026-11 확인) |
|---------|-----------|----------------------------------|
| Claude Code | Anthropic | Claude **Pro 이상 유료** 요금제. 무료 요금제로는 쓸 수 없다 |
| GitHub Copilot | GitHub(Microsoft) | 무료(Copilot Free, 사용량 제한). 학생 인증하면 **Copilot Student 무료** |
| Codex | OpenAI | ChatGPT 요금제. VS Code 확장·명령줄은 **Plus 이상 권장**(무료 요금제에서 되는지 확인 필요) |

> 돈을 내지 않고 시작하려면 **Copilot**부터 설치한다. 요금제와 무료 범위는 회사가 자주 바꾸므로 각 회사 요금 페이지를 다시 확인한다.

---

## 1. Git 설치
Git은 파일의 변경 이력을 저장하는 프로그램이다.

**Windows**
1. https://git-scm.com/download/win 에서 설치 파일을 받아 실행한다.
2. 선택 화면은 모두 기본값으로 **Next**를 누른다. (Git Bash라는 터미널도 함께 깔린다. Claude Code가 이것을 쓴다.)

**Mac**
1. 터미널 앱(응용 프로그램 → 유틸리티 → 터미널)을 연다.
2. `git --version` 을 입력한다. 설치 안내 창이 뜨면 **설치**를 누른다(Xcode 명령줄 도구가 깔린다).

**둘 다 — 내 이름 등록 (한 번만)**
```bash
git config --global user.name "홍길동"
git config --global user.email "GitHub에-가입한-이메일@example.com"
```

## 2. GitHub 계정 만들기
1. https://github.com 에서 **Sign up**. 학교 이메일로 가입하면 학생 인증이 쉽다.
2. (선택·권장) 학생 인증: https://education.github.com → **Join GitHub Education** → 학생증이나 학교 이메일로 신청한다.
   승인되면 Copilot Student 등 학생 혜택을 받는다. 승인까지 며칠 걸릴 수 있다.

## 3. VS Code 설치
VS Code는 마이크로소프트가 만든 무료 편집 프로그램이다. 글과 코드를 쓰고, AI 도구를 붙여 쓴다.

- https://code.visualstudio.com 에서 내 운영체제용을 받는다.
- **Windows**: 설치 중 "PATH에 추가", "Code로 열기 작업 추가" 체크박스를 모두 켠다.
- **Mac**: 받은 파일을 **응용 프로그램** 폴더로 옮긴다. VS Code를 열고 `Cmd+Shift+P` → `Shell Command: Install 'code' command in PATH` 를 실행한다.
- 한국어 화면: 확장(왼쪽 네모 4개 아이콘, `Ctrl+Shift+X` / Mac `Cmd+Shift+X`)에서 **Korean Language Pack** 설치 후 재시작.
- VS Code 왼쪽 아래 사람 모양 아이콘 → **GitHub로 로그인**.

## 4-A. Claude Code 확장 설치
1. 확장 탭에서 **Claude Code**를 검색한다. 만든 곳이 **Anthropic**인지 확인하고 설치한다(확장 ID `anthropic.claude-code`). VS Code 1.94 이상이 필요하다.
2. 오른쪽 아래 상태 표시줄의 **✻ Claude Code**를 누르거나, 파일을 연 상태에서 오른쪽 위 불꽃 모양 아이콘을 누른다.
3. **Sign in** → 웹브라우저에서 Claude 계정으로 로그인한다.
4. (선택) 터미널에서 `claude` 명령도 쓰고 싶으면 따로 설치한다. 확장만 쓸 거라면 건너뛴다.
   - Mac 터미널: `curl -fsSL https://claude.ai/install.sh | bash`
   - Windows PowerShell: `irm https://claude.ai/install.ps1 | iex`
   - 새 터미널을 열고 `claude --version` 으로 확인한다.

## 4-B. GitHub Copilot 설치
1. VS Code 아래 상태 표시줄의 Copilot 아이콘 → **Use AI Features**, 또는 `Ctrl+Shift+P`(Mac `Cmd+Shift+P`) → `GitHub Copilot: Sign in`.
2. GitHub 계정으로 로그인한다. 구독이 없으면 Copilot Free로 자동 가입된다.
3. 학생 인증을 받았다면 https://github.com/settings/education/benefits 에서 **Copilot Student**를 켠다.
4. 채팅 창: `Ctrl+Alt+I`(Mac `Ctrl+Cmd+I`) 또는 상단의 채팅 아이콘. 확장 이름·단축키는 VS Code 버전에 따라 달라질 수 있다(확인 필요).

## 4-C. OpenAI Codex 설치
1. 확장 탭에서 **Codex**를 검색해 OpenAI가 만든 확장(ID `openai.chatgpt`)을 설치한다.
2. **Sign in with ChatGPT** → ChatGPT 계정으로 로그인한다.
3. (선택) 명령줄 도구:
   - Mac 터미널: `curl -fsSL https://chatgpt.com/codex/install.sh | sh`
   - Windows PowerShell: `powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"`
4. 이 폴더를 처음 열 때 "이 프로젝트를 신뢰하는가(trust)"를 물으면 **신뢰**를 고른다. 그래야 `.codex/config.toml` 설정이 적용된다.
