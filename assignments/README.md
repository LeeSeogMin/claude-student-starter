# assignments — 과제 폴더

과제마다 하위 폴더를 하나씩 만든다.

```
assignments/
  01-자기소개/
    보고서.md
  02-데이터분석/
    analysis.py
    data.csv
```

- 폴더 이름은 `번호-짧은제목` 형식으로 쓰면 순서대로 정렬된다.
- 한글(.hwp)·워드(.docx) 파일도 넣을 수 있다. 다만 Claude는 `.md`·`.txt`·코드 파일을 가장 잘 읽는다.
- 개인정보(학번, 전화번호)가 든 파일은 공개 레포에 올리지 않는다. 내 레포를 **Private**으로 만들면 안전하다.
